# Code of Conduct

## Our Standards

We want NL-Tools to be a welcoming and respectful open-source project for everyone.

Contributors are expected to:

- Be respectful and professional.
- Give constructive feedback.
- Accept different opinions and approaches.
- Focus on what is best for the project and its users.
- Take responsibility for mistakes and learn from them.

Unacceptable behavior includes harassment, discrimination, personal attacks, trolling, and other inappropriate or disrespectful conduct.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

If you experience or witness unacceptable behavior, please report it privately to the project maintainer.

## Scope

This Code of Conduct applies to all project spaces, including the GitHub repository, issues, pull requests, discussions, and other project-related communication.

## Reporting

If you experience or witness unacceptable behavior, please contact the project maintainer through the contact information available on the project's GitHub profile.

All reports will be handled as confidentially as reasonably possible.

## Attribution

This Code of Conduct is based on common open-source community standards and has been adapted for NL-Tools.
