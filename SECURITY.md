Security Policy

Supported Versions

Only the latest released version of NL-Tools is currently supported with security updates.

Version	Supported
1.0.x	Yes
< 1.0	No

Reporting a Vulnerability

If you discover a security vulnerability in NL-Tools, please do not report it through a public GitHub issue.

Instead, please contact the project maintainer privately with:

* A description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Any suggested fixes, if available

Please include enough information to reproduce and understand the issue.

Response

Security reports will be reviewed as soon as possible.

If the vulnerability is confirmed, appropriate steps will be taken to address the issue and release a fix when necessary.

Please do not publicly disclose the vulnerability until a fix has been released.

Disclosure

Once a security issue has been resolved, relevant information may be included in the project’s changelog or release notes.

The disclosure will avoid exposing unnecessary details that could put users at risk.
